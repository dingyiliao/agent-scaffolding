# Preset: fallback (兜底)

适用：类型识别不自信、或项目确实不归属任一类型时走这套。这是原本的单一模板，作为安全网保留。

## 章节大纲

接在通用的 元数据头 / 问题域 / 概念与术语 之后：

- **设计思路** ——核心抽象、设计哲学、关键架构决策
- **代码组织** ——模块清单表（名 / 一句话职责 / LoC / 关键入口文件），列全。**不做加权打分**；模块多时选 3–5 个粗体段落详写，并显式列出"未详写模块"。
- 协议与分发 / 特点与不足（通用）

## 各档关注点

- `quick`：列模块清单，不深入
- `medium`：设计思路成段；选 3–5 个模块详写
- `deep`：每个模块一段简评；视情况添加项目独有章节（如配置 / 性能 / 安全等）
